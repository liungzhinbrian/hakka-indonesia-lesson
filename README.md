## 詞彙卡拉霸使用

1. 在第三至第八站開啟「猜一猜詞彙」或「28詞總複習」。
2. 右側按「抽籤拉霸」展開。按「拉霸抽籤」抽一位學生；可持續抽選，不會關閉詞彙卡。
3. 「名單與抽籤設定」可直接填入姓名、座號（一行一筆、或逗號分隔），按「套用名單」；「抽過的人暫不重複」與原輪盤同步。
4. 按「重新抽籤」會清除已抽紀錄，並同步原輪盤。原輪盤的學生名單也會同步到詞彙卡拉霸。
5. 詞彙卡拉霸預設收合；不需要使用時，直接忽略即可。

## 部署至GitHub Pages

將解壓縮後**資料夾內的全部檔案及`assets/`目錄**放在GitHub Pages倉庫根目錄；`index.html`必須位於根目錄，不要只上傳一個HTML檔。保留`app.js`、`content.js`、`culture-vocab.js`、`styles.css`、`phonology-tools.js`、`journey-pixel.html`、`worksheet.html`、`versions.html`及`assets/`。GitHub倉庫的Settings → Pages選擇main分支、root，部署後可按Ctrl+F5重新載入。

### 離線說明

網站在本地靜態伺服器可開啟，教材與原始音檔都在`assets/`；線上YouTube影片及部分外部來源照片需要網路。若瀏覽器直接開啟`file://`造成個別外部資源阻擋，可使用本地靜態HTTP伺服器或GitHub Pages。
