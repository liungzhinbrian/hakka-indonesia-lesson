# 飄洋過海尋客家：印尼客家文化之旅

**版本：beta V6.1.0**  
**網頁設計／原始程式碼設計：曾櫳震老師**

高中客語互動教材，包含海陸與四縣課文、臺灣與印尼客家社群分布、歷史遷徙、蘭芳公司、語言傳承、飲食與元宵文化，以及課堂輔助工具。

## V6.1.0更新內容

- 網站名稱改為「高中客語／飄洋過海尋客家：印尼客家文化之旅」，頁尾顯示版本號及設計署名。
- 全站站別保留「第1站、第2站……」，移除章節時間標籤及「45分鐘·互動探索」。
- 地圖的「客家原鄉」可選擇「往臺灣移民」或「往南洋移民」，每次只顯示所選方向的路線動畫；移除臺灣到印尼的現代航線。
- 臺灣地圖標示新竹縣、新竹市、桃園市、苗栗縣、臺中市、雲林縣、高雄市、屏東縣、花蓮縣與臺東縣；點選縣市可顯示客家人口、比例、主要與其他腔調。
- 各縣市標記加入循環擴散光暈，熱區顏色沿用前版臺灣地圖素材；人口資料採用客委會110年調查結果。
- 課堂工具新增碼錶、倒數計時器（15秒、30秒、1分鐘、2分鐘、3分鐘、5分鐘）及輪盤抽籤；輪盤可貼上姓名／座號，支援不重複抽籤。
- 移除地圖上的免責提示、教師備忘及學生畫面中的參考性說明；詳細來源仍可從側欄「資料與圖片來源」查詢。
- 側欄預留「教案下載」，在教案尚未完成前顯示「尚未提供」，不會產生空白或無效下載檔案。
- 延續beta V5.0的調值（上標）與調型切換、雙腔課文與詞彙卡。

## 使用方式

1. 將整個資料夾解壓縮，直接以Chrome、Edge或Firefox開啟根目錄`index.html`，或透過GitHub Pages上課。
2. 左側選擇教學站別，上方切換「海陸／四縣／雙腔」「拼音」「標音：調值／調型」，並可放大字級。
3. 第一站選擇「東亞與東南亞」，點「客家原鄉」後選擇移民方向。切換「臺灣客家人口」可點縣市查閱人口數與腔調；「印尼客家聚居地」可點社群位置。
4. 右上「課堂工具」可使用碼錶、倒數計時及輪盤。輪盤名單只在本機瀏覽器內使用，不會自動上傳。
5. 左側「下載／列印學習單」開啟`worksheet.html`，可用瀏覽器列印功能列印A4學習單。

### 教案完成後啟用下載

在`assets/docs/`資料夾放入`lesson-plan.pdf`，再將`app.js`頂部的：

```js
const LESSON_PLAN_FILE = '';
```

改成：

```js
const LESSON_PLAN_FILE = 'assets/docs/lesson-plan.pdf';
```

更新GitHub後，側欄按鈕將自動啟用下載。這一版沒有建立假的教案檔案。

### 音訊

實際臺灣海陸與印尼山口洋客語錄音需另外加入。現在可在「海外客語」上傳本機音訊暫時播放，檔案不會傳送至網站伺服器；正式配置方式：

```js
const BUILTIN_AUDIO = {
  tw:'assets/audio/taiwan-hailu.mp3',
  id:'assets/audio/singkawang-hakka.mp3'
};
```

請同步上傳對應的音訊檔至`assets/audio/`。
