# 飄洋過海尋客家：印尼客家文化之旅

**beta V6.2.3｜2026-11-10**  
網頁設計／原始程式碼設計：曾櫳震老師

## 安裝於GitHub Pages
1. 解壓縮下載的ZIP，**不要把ZIP直接上傳**。
2. 將 `index.html`、`app.js`、`content.js`、`styles.css`、`worksheet.html` 上傳到儲存庫根目錄。
3. 上傳 `assets/images/`、`assets/audio/` 內所有檔案，保留相對目錄名稱。**不需要上傳影片檔**。
4. GitHub儲存庫設定：Settings → Pages → Deploy from a branch → `main` / `/(root)`。
5. GitHub Pages完成部署後按 `Ctrl+F5` 強制重新整理。

### 課堂操作
- `→`或PageDown進入下一站；`←`或PageUp返回上一站。
- 點選「廣東、福建原鄉」選擇往臺灣或南洋，移民動畫互斥顯示。
- 「海陸／四縣／雙腔」「拼音開關」「標音調值／調型」可在上方切換。
- 右上方可開啟碼錶、倒數計時器、抽籤輪盤；按 `F`全螢幕。
- 第五站「蘭芳公司動畫｜客語版」可打開YouTube嵌入播放器；亦可開啟YouTube觀看，關閉資訊卡會卸載播放器並停止播放。
- 第六站兩邊的照片獨立輪播；點‹／›切換，點圓點跳至指定照片，按「暫停」停止自動換圖。
