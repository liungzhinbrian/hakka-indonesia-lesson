# 飄洋過海尋客家：印尼客家文化之旅 — beta V6.0.1

## 修正重點
- 修正倒數計時器初始化單位：60秒應是60000毫秒，而非60毫秒。
- 整合 `tools.js` 至 `app.js`、`tools.css` 至 `styles.css`，避免只更新舊版核心檔案時遺漏新工具所需檔案，造成工具按鈕無法使用。
- 保留原有內容及互動：八站導覽、調值上標／調型切換、海陸／四縣、地圖分頁與移民路線、人口資訊卡、碼錶、倒數計時、抽籤輪盤。

## 安裝與更新至GitHub Pages
1. 解壓縮ZIP，不要直接上傳ZIP本身。
2. 上傳根目錄的 `index.html`、`styles.css`、`app.js`、`content.js`、`worksheet.html` 至儲存庫的**根目錄**。
3. 把 `assets/images/` 內的圖片／地圖素材依原資料夾結構上傳，不能只上傳原始碼而漏掉圖片。
4. GitHub Pages設定使用 `main`／`/(root)`，網站部署完成後重新整理。

**注意：** 此版的課堂工具已整合進 `app.js` 和 `styles.css`，不需要另外上傳 `tools.js` 或 `tools.css`。原儲存庫如有這兩個舊檔，不影響新版運作，因為新的 `index.html` 不再引用它們。
