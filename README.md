# 飄洋過海尋客家：印尼客家文化之旅｜beta V8.0.1

高中客語第八課〈行讀客家世界：印尼客家之旅〉的八站式互動教學網站。保留海陸／四縣切換、調型／調值切換、課文朗讀、文化資訊卡、移民地圖、像素冒險過場、圖片與WAV音檔、詞彙卡、28詞總複習，以及碼錶、倒數計時器、輪盤抽籤等功能。

## V8.0.1新增

1. 在第三站「1777年：羅芳伯與蘭芳公司」資訊卡及詳情視窗中，讓羅芳伯肖像完整顯示、不裁切臉部，其餘圖像排版不變。
2. 在各站大型詞彙卡右側加入可收合拉霸；詞彙卡開著時仍可抽籤。拉霸與原輪盤共用姓名／座號名單、已抽記錄及不重複設定。
3. 增加頁首／左側「版本更新紀錄」入口；`versions.html`可直接在瀏覽器閱讀；`CHANGELOG.md`保存詳細日誌；`docs/CHANGELOG_original_V7.0.3.md`保留舊檔供查核。
4. 第八站詞彙總複習不再顯示多餘的教學操作註解；「保留、改變、融合」三張資訊卡預設隱藏說明及例子，點擊卡片才揭曉。
5. 第八站正文移除「收回學習單前」區塊，學習單連結統一收在左側導覽。

## 詞彙卡拉霸使用

1. 在第三至第八站開啟「猜一猜詞彙」或「28詞總複習」。
2. 右側按「抽籤拉霸」展開。按「拉霸抽籤」抽一位學生；可持續抽選，不會關閉詞彙卡。
3. 「名單與抽籤設定」可直接填入姓名、座號（一行一筆、或逗號分隔），按「套用名單」；「抽過的人暫不重複」與原輪盤同步。
4. 按「重新抽籤」會清除已抽紀錄，並同步原輪盤。原輪盤的學生名單也會同步到詞彙卡拉霸。
5. 詞彙卡拉霸預設收合；不需要使用時，直接忽略即可。

## 部署至GitHub Pages

將解壓縮後**資料夾內的全部檔案及`assets/`目錄**放在GitHub Pages倉庫根目錄；`index.html`必須位於根目錄，不要只上傳一個HTML檔。保留`app.js`、`content.js`、`culture-vocab.js`、`styles.css`、`phonology-tools.js`、`journey-pixel.html`、`worksheet.html`、`versions.html`及`assets/`。GitHub倉庫的Settings → Pages選擇main分支、root，部署後可按Ctrl+F5重新載入。

### 離線說明

網站在本地靜態伺服器可開啟，教材與原始音檔都在`assets/`；線上YouTube影片及部分外部來源照片需要網路。若瀏覽器直接開啟`file://`造成個別外部資源阻擋，可使用本地靜態HTTP伺服器或GitHub Pages。

### 版本紀錄可靠性

V6及後續多數版本依原`CHANGELOG.md`整理；V6.2.1、V7.0.1、V7.0.2依程式碼的版本註記補登。V4、V5.0有先前討論摘要，V1至V3缺少可核實逐版資料，已清楚標註；不猜測缺失的版本細節。詳見`versions.html`。
