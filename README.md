# 飄洋過海尋客家：印尼客家文化之旅｜V1.0.0

高中客語第八課〈行讀客家世界：印尼客家之旅〉的八站式互動教學網站。

- 線上網址：https://liungzhinbrian.github.io/hakka-indonesia-lesson/
- 目前版本：V1.0.0（2026-11-19）。beta版已經完成測試，此後為正式版。
- 版本紀錄：網站內「版本更新紀錄」（`versions.html`）或 `CHANGELOG.md`。
- 網頁設計／原始程式碼設計：曾櫳震老師。

## 功能

- 八個教學站：認識印尼、課文閱讀、移民歷史與蘭芳公司、飲食文化比較、元宵節、兩地客語錄音、語言傳承、文化統整。
- 課文海陸腔／四縣腔／雙腔切換，拼音開關，調值／調型切換，字級小、中、大三段。
- 詞彙卡與28詞總複習；第四站三組米食照片輪播（菜包與Choi Pan、客家粽與Bakcang／Nyuk Cung、粢粑與Kaloci）。
- 第一站地圖：東亞與東南亞遷移路線、臺灣客家人口（可縮放、拖曳）、印尼客家聚居地。
- 語音工具：聲調、聲母、元音、新竹海陸腔韻母配字表、原始圖表、連讀變調。
- 課堂工具：碼錶、倒數計時、輪盤抽籤、詞彙卡拉霸；主題動畫可隨時播放。
- 課程學習單：個人學習單PDF可預覽、下載、列印。

## 使用方式

- 教師模式：直接開啟 `index.html`。
- 學生練習模式：網址加上 `?mode=student`，隱藏抽籤與計時工具，保留自學功能。
- 抽籤名單：在輪盤或拉霸的設定中填入，或匯入本機CSV／TXT檔（「班級,姓名」或逐行「101-姓名」）。名單只存在目前的瀏覽器分頁，重新載入後需再匯入。**學生名單是教師私用檔案，不要上傳到這個公開倉庫。**

## 部署

網站是純靜態檔案，放在 GitHub Pages 倉庫根目錄即可（Settings → Pages 選 main 分支、root）。更新時把變動的檔案連同 `assets/` 內的新檔一起上傳，`index.html` 必須在根目錄。上線後若畫面沒有更新，按 Ctrl+F5 重新載入。

## 離線使用

圖片、音檔與學習單都在 `assets/` 內，不需連網。只有蘭芳公司動畫是YouTube嵌入，需要網路。若直接以 `file://` 開啟時個別功能受瀏覽器限制，請改用本機靜態伺服器或線上網址。

## 圖片與資料來源
